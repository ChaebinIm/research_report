# 🧭 지정학 트랙 운영 가이드 (매 회차 참고)

> 이 문서는 '지정학 브리핑(G번호)' 트랙의 상시 운영 지침이다. 매일 아침 자동 실행되는 세션은 새로 시작되므로, 주제 선정 시 이 문서를 먼저 반영한다.
> 최초 작성: 2026-08-07 · 사유: 사용자 피드백 "너무 중동·이란 전쟁 내용만 다룬다. 시장의 관심이 없는 변두리 나라들의 갈등 이야기도 괜찮다. 앞으로 작성할 때 참고해."

## 🚨 최우선 규칙 — 재탕(중복) 금지 (2026-09-28 사용자 피드백 반영)
> 사유: 사용자 피드백 "왜 계속 같은 주제로 자료를 내느냐. 내일부터는 새로운 주제를 내줘라." **G42(2026-09-27 수단·금·아라비아검)가 G17(2026-08-18 수단·금·아라비아검)과 지역·자원 각도가 사실상 동일한 재탕이었다.** 이 실수를 반복하지 말 것.
- **매 회차 = '새 지역 + 새 자원/각도' 조합이어야 한다.** 아래 회차 로그 표를 반드시 대조해, 이미 다룬 (지역 × 자원) 조합은 피한다.
- **"신전개가 있으니 같은 나라를 새 각도로"는 매우 신중히.** 핵심 소재(나라·자원)가 겹치면 사용자에겐 재탕으로 읽힌다. 같은 나라를 또 다루려면 **자원 축·핵심 명제가 확실히 달라야** 하고, 애매하면 아예 다른 지역으로 간다.
- **수단·금·아라비아검(G17·G42), 중동·이란·호르무즈(G01~11), 최근 니치 비철(알루미늄 G39·주석 G40·아연 G41·백금족 G43)은 특히 재탕 주의.** 큰 신규 급성 전개가 없으면 건드리지 않는다.

## 핵심 원칙 — 주제 다양화(중동 편중 완화)
- G01~G11이 전부 **중동·이란·호르무즈**에 쏠렸다. 앞으로는 **주제를 적극 로테이션**한다.
- **"시장이 지금 크게 주목하지 않는 변두리 국가들의 분쟁·자원 갈등"도 환영**한다. 오히려 이 트랙의 학습 목적(분쟁의 구조·역사·시나리오·자원흐름)에 더 잘 맞는다. "그날 가장 임팩트 큰 이슈"라는 기준을 **"학습 가치 + 자원·공급망 연결성 + 구조적 흥미"**까지 포함하도록 넓게 해석한다.
- 최근 회차가 한 지역/이슈(예: 중동)에 **연속으로 쏠려 있으면**, 특별히 큰 신규 전개가 없는 한 **다른 지역·성격의 이슈로 전환**한다. 중동은 '큰 신규 전개가 있을 때'만 다시 다룬다.
- 같은 이슈를 이어갈 때는 반드시 **새로운 전개·각도**로.

## 유지되는 기존 규칙
- 5개 축(현황+격화확률 / 역사 사례 표 / 자원 흐름 / 시나리오 A·B·C / 국내 섹터·종목코드, 매매추천 아님) 유지.
- 고급 수준, 10~15분 분량, 표·불릿 적극 활용.
- 전황 수치는 보도 기준 유동적임을 명시, 과거 사례는 확정 사실로 구분.
- **검증 규칙**(`claude/검증규칙-필수.md`) 상시 적용 — 시장 수치 2소스 교차확인, 장중치를 종가로 쓰지 않기. **본문에 쓴 특정 주장(예: 기업의 특정 프로젝트 수주)은 반드시 근거 소스에서 실제 확인 후 기재.** 단, PGM 등 글로벌 상품 스팟 시세는 '마감/종가' 개념이 없으므로 **조회시점을 병기**해 확정 종가로 오인하지 않게 함.
- 파일명 `지정학/YYYY-MM-DD_Gxx_주제.md`, 프로젝트 저장 + 채팅 전달 + SendUserFile. GitHub 커밋 안 함.
- **프로젝트 용량 주의**: 지식베이스가 상한(2,000,000 토큰)에 근접/초과하면 신규 저장이 거부된다(2026-09-28 G42 저장 실패 사례). 저장 실패 시 사용자에게 알리고, 오래된·중복 문서 정리로 공간 확보 후 저장. (참고: G43은 2026-09-28 정상 저장됨.)

## 회차 로그 (다음 회차 번호·중복 방지용)
